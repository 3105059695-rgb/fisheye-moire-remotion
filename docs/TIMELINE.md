# 2 秒复刻时间线

参考：https://motionface.cc/?recording=7f6a33d3-83e5-4c41-89fe-0910881e46c6

画布 1080 × 1102，30 fps，60 帧。下表时间对应实际视频帧，而非容器音轨尾部。

| 帧 / 时间 | 已观察的画面 | 还原要求 |
| --- | --- | --- |
| 0 / 0.000 s | 灰色默认头像靠近顶中；短信四行大字，左侧裁切；画面已有凸面畸变和横纹 | 第一帧直接进入界面，无淡入；保留近景裁切 |
| 6 / 0.200 s | 相比首帧仅轻微移动 | 主要镜头运动此时刚开始，不做弹跳 |
| 15 / 0.500 s | 头像右移并缩小，短信上移；右端文字变小，整屏倾斜 | 同一完整界面持续透视运动，文字和纹理一起变形 |
| 23 / 0.767 s | 空间姿态接近终态，消息中央上沿约 y=380 | 在约 0.8–1.0 s 平滑减速稳定 |
| 30 / 1.000 s | 稳定后的短信，没有黄色底色 | 强调进度恰为零 |
| 31 / 1.033 s | “浙”左侧开始出现窄黄色底色 | 左边固定，右边向外扩张 |
| 40 / 1.333 s | 黄色可见 x≈251–391 | 擦出已经完成约 80%，逐渐减速 |
| 45 / 1.500 s | 黄色可见 x≈251–415，覆盖“浙大”主体 | 不能把整个“浙大通”都染黄 |
| 51 / 1.700 s | 黄色达到最终边界 x≈251–425 | 结束强调动画，保持 |
| 59 / 1.967 s | 与前面稳定帧构图一致，保留黄色强调 | 以完整画面结束，不加黑场或片尾 |

## 黄色强调测量

对解码 RGB 像素用条件 `R > 110 && G > 90 && B < 85 && R - B > 60` 检查。测量结果包含编码边缘误差，不代表矢量图形的精确坐标。

| 帧 | 黄色最左 x | 黄色最右 x | 大致 y 范围 |
| --- | --- | --- | --- |
| 30 | 无 | 无 | 无 |
| 31 | 251 | 271 | 604–715 |
| 32 | 251 | 290 | 604–715 |
| 33 | 251 | 307 | 603–717 |
| 34 | 251 | 323 | 604–717 |
| 35 | 251 | 337 | 604–717 |
| 40 | 251 | 391 | 604–717 |
| 45 | 251 | 415 | 604–717 |
| 50 | 251 | 424 | 604–717 |
| 51 | 251 | 425 | 604–717 |
| 59 | 251 | 425 | 604–717 |

推荐初始曲线：`easeOutCubic(clamp((frame - 30) / 21, 0, 1))`。这是根据测量推断出的近似函数，不是已知的原始实现。

## 音频

参考 AAC 音轨的完整解码数据为零。时间线中没有需要跟随的语音、音乐节拍或声效；复刻不加入额外声音。视频仍按 60 帧结束，不为静音 AAC 尾部增加帧。
